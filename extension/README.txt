OmniGrab 3.3 — расширение для Chrome / Edge / Brave / Opera / Yandex

1. Распакуйте этот ZIP в постоянную папку.
2. Откройте chrome://extensions или edge://extensions.
3. Включите Режим разработчика → Загрузить распакованное.
4. Выберите папку с manifest.json.
5. Запустите OmniGrab.exe, откройте раздел Расширение и скопируйте код.
6. В значке расширения введите код и нажмите Подключить.
7. Включите видео на сайте. Нажмите кнопку над плеером или отправьте страницу из значка расширения.

После установки не удаляйте папку расширения. Программа должна быть запущена.
Расширение работает только с локальным загрузчиком на этом ПК; никаких внешних серверов OmniGrab нет.
Реестр найденных потоков очищается при переходе на новую страницу.
DRM-потоки не поддерживаются. Вход в аккаунт сайта расширение автоматически не переносит.

КНОПКА НАД ПЛЕЕРОМ
Перетаскивайте за ⠿ слева: положение запоминается. Без наведения кнопка полупрозрачная;
при воспроизведении скрывается через 2,2 секунды без движения мыши. Движение мыши над видео возвращает кнопку.
× справа скрывает её до перезагрузки страницы. Отправить видео всегда можно через значок расширения.
Для обновления замените файлы в прежней папке, нажмите ↻ на странице расширений и обновите вкладку с видео.

ЛЮБЫЕ ФАЙЛЫ
Начните обычную загрузку в браузере: расширение передаст её программе. Переключатель есть в значке расширения.
Если программа выключена или источник требует браузерную сессию, загрузка останется в браузере.
Правая кнопка по ссылке → «Скачать файл в OmniGrab»; для страниц с плеером → «Скачать видео со страницы в OmniGrab».
По умолчанию нет фильтра типов и размера. Новые разрешения: управление скачиваниями, контекстное меню и восстановление передач.
