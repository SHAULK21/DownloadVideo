# OmniGrab 3.0.1

Локальный загрузчик видео и аудио для Windows 10/11 x64 с расширением Chromium. Вместо симуляции используется yt-dlp; отдельные дорожки объединяются FFmpeg. Программа запускается из одного EXE и открывает интерфейс в браузере. Окно EXE должно оставаться открытым во время скачивания.

## Использование

1. Запустите `OmniGrab.exe`, дождитесь открытия интерфейса.
2. Добавьте ссылку, при необходимости нажмите «Распознать» и выберите доступный формат.
3. Для расширения распакуйте `OmniGrab-Extension.zip`, включите режим разработчика на `chrome://extensions` и загрузите распакованную папку. В Edge используется `edge://extensions`.
4. Во вкладке «Расширение» программы получите код и введите его в popup расширения.

Подробная инструкция: [README-Windows.txt](README-Windows.txt).

В версии 3.0.1 добавлен собственный адаптер LuluStream (`luluvido.com`, `luluvid.com`, `lulustream.com`, ссылки `/e/` и `/d/`). Он распаковывает данные JWPlayer без исполнения скриптов сайта, получает настоящий HLS/DASH и сохраняет Referer. При повторной попытке адрес потока запрашивается заново. Для blob-плееров расширение выбирает единственный обнаруженный поток того же фрейма; при неоднозначности можно выбрать поток в popup. Сохраняются только Referer, Origin и User-Agent, без cookies.

Прямые файлы, поддерживаемые сайты, HLS/DASH, извлечение MP3 и плейлисты обрабатываются реальными экстракторами. Поддержка конкретного сайта зависит от yt-dlp и доступности источника. DRM не поддерживается; вход из браузера автоматически не переносится. Для больших плейлистов за один анализ выбираются первые 100 записей. Постоянных внешних серверов OmniGrab нет.

## Состояние и безопасность

Задачи и настройки сохраняются в `%LOCALAPPDATA%\OmniGrab\state.json` с атомарной заменой и резервной копией. После перезапуска незавершённые задачи ставятся на паузу; их можно продолжить. Файлы и `.part` не удаляются при удалении строки из списка. Сервис слушает только `127.0.0.1:17893`; API требует токен, расширение получает его через шестизначный код. Повторный запуск EXE открывает уже работающий экземпляр. Параллельность означает число фрагментов HLS/DASH, а не вымышленное ускорение любого HTTP-файла. Лимит скорости распределяется между максимальным числом задач и фрагментов консервативно, поэтому фактическая скорость может быть ниже него.

## Разработка

Требуется Node.js **24.19.0** и npm. Используется `package-lock.json`.

```sh
npm ci
npm run lint
npm run build
```

Для запуска из исходников установите yt-dlp и FFmpeg/FFprobe либо задайте `OMNIGRAB_YTDLP` и `OMNIGRAB_FFMPEG` полными путями. Затем `npm start`; используйте напечатанный адрес с токеном. В Windows бинарные инструменты можно подготовить командой ниже и указать переменные на `release/yt-dlp.exe` и `release/ffmpeg.exe`.

```sh
node scripts/prepare-binaries.mjs
npm run build:windows
```

Windows Node, yt-dlp и архив FFmpeg проверяются по закреплённым SHA256. Если upstream заменит изменяемый FFmpeg `latest`, подготовка остановится: новую версию и контрольные суммы следует пересмотреть явно. Инструменты сжимаются и встраиваются в Node SEA вместе с UI. При первом запуске они извлекаются в пользовательский каталог; установки Node/Python на целевом ПК не требуется. Сборка выполняется на Windows или Linux x64, без code cache и snapshots.

```sh
npm test
# тесты реальных загрузок требуют yt-dlp, ffmpeg и ffprobe в PATH
# или OMNIGRAB_YTDLP=полный_путь
CHROMIUM_PATH=/path/to/chromium npm run test:browser
node tests/sea-smoke.mjs release/OmniGrab.exe
```

Тесты покрывают байты и SHA256, 404, лимит параллельности, паузу/resume, перезапуск, HLS, MP3, резервную копию, API и жизненный цикл расширения. Проверка браузера требует установленного Chromium; её можно запускать отдельно. В CI Windows дополнительно проверяется запуск упакованного EXE с реальным скачиванием.

## Структура

- `desktop/manager.mjs` — планировщик, хранение и запуск процессов.
- `desktop/server.mjs` — локальный API, сопряжение, UI и готовые файлы.
- `desktop/main.mjs` — запуск, извлечение встроенных инструментов, завершение.
- `src/` — интерфейс React, реальные метаданные и состояния.
- `extension/` — отдельные исходники Manifest V3.
- `plugins/` — встроенный в EXE адаптер LuluStream для yt-dlp.
- `scripts/` — ZIP, проверка бинарников и сборка Windows SEA.
- `tests/` — регрессионные и интеграционные проверки.

Лицензии и ссылки на исходники сторонних компонентов: [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt).
