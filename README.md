# OmniGrab 3.2

Приложение для Windows 10/11 x64: отдельное окно, трей и очередь загрузок. Интерфейс открывается внутри приложения, без вкладки браузера и консоли. Крестик сворачивает окно в трей; загрузки продолжаются. «Выход» завершает работу с сохранением очереди.

## Использование

1. Запустите `OmniGrab.exe`, добавьте ссылку и выберите папку загрузок.
2. «Распознать» показывает доступные форматы; поддерживаются HLS/DASH, MP3 и плейлисты (первые 100 записей при анализе).
3. Для браузера распакуйте `OmniGrab-Extension.zip`, загрузите папку через `chrome://extensions` или `edge://extensions` в режиме разработчика и введите код из раздела «Расширение» программы.
4. Возвращайте окно через значок возле часов, повторный запуск EXE или кнопку расширения «Открыть программу».

Инструкция: [README-Windows.txt](README-Windows.txt). При обновлении с 3.0/3.0.1 сначала закройте старую консоль через Ctrl+C. Очередь и настройки в `%LOCALAPPDATA%\OmniGrab` сохраняются.

## Поведение и безопасность

Скачивание выполняет yt-dlp, объединение дорожек и MP3 — FFmpeg. Данные очереди записываются атомарно с резервной копией. При выходе незавершённые задачи останавливаются и сохраняются на паузе; удаление строки не удаляет файлы. Один экземпляр приложения на каталог данных; размер и положение окна сохраняются.

Окно Electron использует изолированный renderer: sandbox и contextIsolation включены, nodeIntegration выключен. Загружаются только упакованные ресурсы приложения через loopback; внешняя навигация, popup и webview запрещены. Нативные диалоги выбирают папку и сохраняют ZIP расширения. API слушает только `127.0.0.1:17893`, требует токен; расширение подключается по коду. «Открыть программу» восстанавливает окно, не создавая вкладку.

Адаптер LuluStream обрабатывает `luluvido.com`, `luluvid.com` и `lulustream.com`, ссылки `/e/` и `/d/`: декодирует данные JWPlayer без исполнения скриптов сайта, получает настоящий поток и сохраняет Referer. При повторной попытке адрес потока запрашивается заново. Расширение передаёт реальный поток того же фрейма для blob-плееров; при неоднозначности остаётся ручной выбор в popup. Передаются только Referer, Origin и User-Agent; cookies не переносятся.

Поддержка конкретного сайта зависит от yt-dlp и доступности источника. DRM не поддерживается. Обычный HTTP-файл использует одно соединение; настройка фрагментов относится к HLS/DASH. Лимит скорости распределяется консервативно.

## Разработка и сборка

Node.js 24.19.0, npm, Electron 44.8.0, electron-builder 26.15.3. Версии закреплены в package-lock.json.

```sh
npm ci
npm run lint
npm run build
npm start
```

Для разработки на Windows подготовьте инструменты через `node scripts/prepare-binaries.mjs`, либо задайте `OMNIGRAB_YTDLP` и `OMNIGRAB_FFMPEG`. В непакованном запуске используются инструменты из `release/`; при необходимости можно задать другие полные пути переменными среды. Для других ОС нужны yt-dlp и FFmpeg в PATH.

```sh
npm run build:windows
```

Сборка на Windows создаёт переносимый `release/OmniGrab.exe` с GUI-подсистемой, без консоли, и `release/OmniGrab-Extension.zip`. Runtime, yt-dlp, FFmpeg/FFprobe, Node для JS-экстракторов и адаптер сайта входят в пакет. Инструменты проверяются по закреплённым SHA256. При изменении upstream-архива FFmpeg сборка остановится до пересмотра контрольных сумм.

```sh
npm test
node tests/desktop-smoke.mjs release/desktop-build/win-unpacked/OmniGrab.exe
node tests/portable-smoke.mjs release/OmniGrab.exe
```

Базовые тесты проверяют SHA256 загрузок, 404, очередь, HTTP Range resume, перезапуск, HLS/DASH, MP3, API и расширение. Windows smoke запускает реальное окно, проверяет изоляцию, нативные диалоги, загрузку через UI, фоновые загрузки после закрытия окна, pairing, повторный запуск, выход и восстановление. Отдельно запускается итоговый переносимый EXE с проверкой GUI-подсистемы и SHA256 скачанного файла.

## Структура

- `desktop/electron.mjs` — окно, трей, диалоги и жизненный цикл.
- `desktop/manager.mjs` — очередь, сохранение и процессы yt-dlp.
- `desktop/server.mjs` — локальное API для окна и расширения.
- `src/` — интерфейс React.
- `extension/` — расширение Manifest V3.
- `plugins/` — адаптер LuluStream.
- `scripts/` — ZIP, проверка инструментов и сборка Windows.
- `tests/` — регрессионные и интеграционные проверки.

Лицензии: [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt). Electron/Chromium сохраняют свои файлы лицензий в runtime переносимого приложения.

### Исправление переносимой сборки 3.1.1

Компоненты скачивания проверяются по SHA256 и копируются в постоянную папку данных до запуска очереди. Отсутствующие или повреждённые файлы восстанавливаются из EXE. Повторные запуски используют независимые временные каталоги; второй экземпляр больше не удаляет компоненты первого. Для закреплённого electron-builder 26.15.3 параметр `portable.unpackDirName: true` отключает `UNPACK_DIR_NAME` в шаблоне NSIS (проверено по установленному `NsisTarget.js`; описание boolean в документации этой версии расходится с кодом). Тест итогового EXE запускает второй экземпляр во время загрузки, затем проверяет анализ и новую загрузку, а также восстановление компонентов после перезапуска. Расширение 3.1.0 совместимо.

### Версия 3.2

Общие аргументы анализа и скачивания отключают обработчики запрета по домену (`--use-extractors default,-piracy,-liability,-drm`). Остальные экстракторы, включая Generic и локальный Lulu, сохраняются. Обработка фактического зашифрованного потока не меняется. Интеграционный тест с локальным HTTP-прокси воспроизводит исходный отказ `[Piracy]` без запроса к сайту, затем проверяет анализ свободного тестового видео на доменах из трёх списков и SHA256 реального скачивания.

Кнопка расширения 3.2 перемещается за ручку, запоминает относительную позицию, остаётся в пределах окна при изменении размера, становится полупрозрачной без наведения и скрывается через 2,2 секунды без движения мыши во время воспроизведения. Движение над видео возвращает кнопку. Крестик скрывает кнопку до перезагрузки страницы; popup продолжает работать. Невидимая кнопка пропускает клики к плееру. Для клавиатуры предусмотрены фокус, стрелки и Home. Поддержаны контейнеры полноэкранных плееров; в нативном полноэкранном video оверлей скрывается. Тест в Chromium проверяет мышью перетаскивание, скачивание, автоскрытие и пропуск кликов на коде из ZIP расширения.
