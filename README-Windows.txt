OmniGrab 3.0 — Windows 10/11, 64 бит

БЫСТРЫЙ ЗАПУСК
1. Запустите OmniGrab.exe двойным щелчком.
2. Дождитесь автоматического открытия интерфейса в браузере. Первый запуск распаковывает встроенные компоненты.
3. Нажмите Добавить ссылку, вставьте адрес видео. Для выбора качества нажмите Распознать.
4. Выберите папку и Начать скачивание. Статус Сохранено появляется только после получения готового файла.

РАСШИРЕНИЕ
1. Распакуйте OmniGrab-Extension.zip в постоянную папку.
2. Откройте chrome://extensions (Edge: edge://extensions).
3. Включите Режим разработчика → Загрузить распакованное → выберите папку с manifest.json.
4. В интерфейсе программы откройте Расширение. Введите показанный шестизначный код в значке расширения.
5. Откройте сайт, включите видео и нажмите Скачать в OmniGrab. Для blob-плееров используйте Скачать видео со страницы.

ВАЖНО ДЛЯ РАБОТЫ
Не закрывайте окно OmniGrab.exe, пока идёт скачивание. Интерфейс можно закрыть — загрузки продолжатся, пока работает EXE.
Чтобы выйти с сохранением очереди, нажмите Ctrl+C в окне программы. После следующего запуска нажмите Продолжить у незавершённых задач.
Файлы по умолчанию: папка Downloads\OmniGrab вашего пользователя. Путь можно изменить в настройках.
Задачи и настройки: %LOCALAPPDATA%\OmniGrab. Удаление задачи из списка не удаляет файл или недокачанные части.
Обычные MP4 скачиваются одним соединением; параметр параллельности фрагментов относится к HLS/DASH.
Предел скорости распределяется консервативно; при малом числе активных задач скорость может быть ниже заданной.
Раздельные дорожки объединяются через FFmpeg, поэтому MP4/MKV зависит от исходных кодеков. Браузер не воспроизводит все кодеки: такой файл можно открыть обычным видеоплеером.
Нельзя гарантировать загрузку с каждого сайта. DRM не поддерживается; сайт может требовать вход, CAPTCHA или ограничивать доступ. Аккаунт браузера автоматически не передаётся.
Программа содержит Node.js, yt-dlp, FFmpeg и FFprobe. Ничего из этого отдельно устанавливать не требуется.

ПРОВЕРКИ СБОРКИ
Скачивание, контрольные суммы, очередь, пауза/продолжение, восстановление, HLS, MP3 и API проверяются автоматическими тестами на Linux. Интерфейс проверен в Chromium на desktop/mobile.
EXE собран для Windows x64. Отдельная нативная проверка предусмотрена в GitHub Actions; результат смотрите в репозитории.
