OmniGrab 3.3.1 — приложение для Windows 10/11, 64 бит

БЫСТРЫЙ ЗАПУСК
1. Откройте OmniGrab.exe. Появится отдельное окно приложения; браузер и консоль не нужны.
2. Нажмите «Добавить ссылку», вставьте адрес видео. «Распознать» покажет доступное качество.
3. Выберите папку и нажмите «Начать скачивание». Готовый файл отмечается как «Сохранено».
Первый запуск распаковывает переносимое приложение и может занять немного времени.

ОКНО И ЗАГРУЗКИ В ФОНЕ
Крестик сворачивает окно в трей (область значков возле часов). Загрузки продолжаются.
Щёлкните значок OmniGrab в трее, повторно запустите EXE или нажмите «Открыть программу» в расширении, чтобы вернуть окно.
Меню значка: открыть программу, папка загрузок, приостановить/продолжить все, о программе, выход.
Для полного завершения нажмите «Выйти из программы» в окне либо «Выход» в меню значка.
При выходе очередь сохраняется, незавершённые загрузки ставятся на паузу. После запуска нажмите «Продолжить».

РАСШИРЕНИЕ
1. Распакуйте OmniGrab-Extension.zip в постоянную папку.
2. Откройте chrome://extensions (Edge: edge://extensions).
3. Включите «Режим разработчика» → «Загрузить распакованное» → выберите папку с manifest.json.
4. В программе откройте «Расширение». Введите показанный код в значке расширения браузера.
5. Включите видео на сайте и нажмите «Скачать в OmniGrab» над плеером либо выберите поток в значке расширения.
Для blob-плееров используется обнаруженный поток из того же фрейма. Если потоков несколько, выберите нужный в значке расширения.

ОБНОВЛЕНИЕ С ВЕРСИЙ 3.1 / 3.1.1 / 3.2
Выйдите из программы через «Выйти из программы». Замените EXE новым и запустите.
Замените файлы расширения в его прежней папке, нажмите ↻ на странице расширений и перезагрузите вкладку видео.
Очередь, настройки, папки и подключение сохраняются.

ИСПРАВЛЕНИЕ В 3.3.1
Обновлён обработчик Beeg: API получает ID без начальных нулей; поддержаны новые поля названия,
старые и новые источники HLS/MP4 и заголовки Origin/Referer для потока.
Если API не возвращает источник, откройте видео в браузере и выберите обнаруженный HLS/MP4
в значке расширения.
Для обновления с 3.3.0 достаточно полностью выйти из программы, заменить EXE и запустить снова.
Расширение 3.3.0 совместимо и не требует переустановки.

НОВОЕ В 3.3
Добавлен загрузчик обычных HTTP(S) файлов: архивов, документов, программ и изображений.
Расширение по умолчанию перехватывает загрузки браузера; переключатель есть в значке расширения и настройках программы.
Перед остановкой браузерной загрузки программа проверяет доступность файла. Если программа выключена
или источник недоступен без браузерной сессии, загрузка продолжается в браузере.
Передачи восстанавливаются после перезапуска расширения. Состояние промежуточной передачи хранится до подтверждения.
Правая кнопка мыши по ссылке/изображению → «Скачать файл в OmniGrab». Для страницы с плеером выбирайте «Скачать видео со страницы в OmniGrab».
Включён поиск без фильтра типов и минимального размера. Фрагменты HLS/DASH группируются через плейлист, чтобы не добавлять тысячи отдельных кусочков.
Обычные файлы сохраняются без перекодирования и без перезаписи существующих файлов. Пауза и продолжение используют HTTP Range и валидатор источника; если продолжение ненадёжно, файл загружается заново.
Расширению нужны новые разрешения downloads/contextMenus/alarms. После замены файлов нажмите ↻ на странице расширений и подтвердите разрешения, если браузер запросит.
Не перехватываются POST-загрузки и blob/data-файлы, которые браузер не предоставляет как отдельную HTTP(S) ссылку: они остаются в браузере.

СОХРАНЕНО ИЗ 3.2
Отключены запреты yt-dlp по спискам доменов: Piracy, Liability, DRM. Вместо отказа по имени сайта
загрузчик ищет доступный источник. Это не гарантирует наличие потока или поддержки каждого сайта.
Кнопку над плеером можно передвинуть за ⠿ слева; положение запоминается.
Без наведения она полупрозрачная. Во время воспроизведения скрывается через 2,2 секунды без движения мыши;
чтобы вернуть, подвигайте мышью над видео. × справа скрывает кнопку до перезагрузки страницы.
Скачать также можно через значок расширения в панели браузера.
Сохранено исправление ENOENT: компоненты проверяются по SHA256 и восстанавливаются при запуске
в %LOCALAPPDATA%\OmniGrab\runtime. Не удаляйте папку данных во время работы программы.

ОБНОВЛЕНИЕ С ВЕРСИЙ 3.0 / 3.0.1
Закройте старую консоль OmniGrab через Ctrl+C. Замените EXE новым и запустите.
Очередь, настройки и папка загрузок сохраняются: %LOCALAPPDATA%\OmniGrab.
Замените файлы расширения в его прежней папке и нажмите ↻ на странице расширений. Перезагрузите страницу видео.
Поддержка LuluStream / luluvido.com / luluvid.com, HLS/DASH и MP3 сохранена.

ФАЙЛЫ
По умолчанию: Downloads\OmniGrab вашего пользователя. Папка меняется в настройках через диалог Windows.
Удаление задачи из списка не удаляет готовые файлы и недокачанные части.
Положение и размер окна запоминаются. Повторный запуск открывает работающий экземпляр.
Python, Node.js, FFmpeg и браузер для интерфейса отдельно устанавливать не нужно.

ОГРАНИЧЕНИЯ
Поддержка сайта зависит от доступного источника. DRM и автоматический перенос авторизации браузера не поддерживаются.
Обычные MP4 используют одно соединение; параллельность фрагментов относится к HLS/DASH.
При включённом лимите скорости он распределяется консервативно между задачами и фрагментами.
Формат MP4/MKV зависит от исходных кодеков. Для неподдерживаемого предпросмотром кодека откройте файл обычным видеоплеером.

ПРОВЕРКИ
В Windows CI проверяются отдельное окно, отсутствие консольной подсистемы, реальные загрузки с SHA256,
сворачивание в трей и скачивание в фоне, повторный запуск, выход и восстановление очереди, расширение и переносимый EXE.
